Using our parent paper's code, were able to create a more accurate and optimal model that can predict housing prices. To accomplish this, we utilized the finalized, clean dataset given to us by our parent paper titled "final.csv", which is found in the "Datasets" folder. Our novelty is found in the "Our Code" folder, which is titled "Weighted_Ensemble_vs_XGBoost". In this file, we leverage a weighted ensemble approach heavily inspired from our supplemental research papers to improve the model's accuracy. Our weighted ensemble approach specifically utilizes the following models: XGBoost, Random Forest, and Linear Regression.
